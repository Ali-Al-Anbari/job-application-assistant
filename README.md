# Job Application Assistant

A Chrome extension that will help users track and manage job applications.

## Current Features

Right now the project:

* uses React and Vite
* runs as a Chrome extension
* uses Chrome Manifest V3
* opens the React app when the extension icon is clicked

## Running the Project

Install dependencies:

npm install

Run the normal React development server:

npm run dev

Build the Chrome extension:

npm run build

Then:

1. Open `chrome://extensions`
2. Turn on Developer Mode
3. Click **Load unpacked**
4. Select the `dist` folder
5. Open the Job Application Assistant extension
